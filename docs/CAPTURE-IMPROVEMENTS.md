# 截图连续性与留白优化

2026-11-01，项目：<repo>。

针对长图断层、重复的向下按钮、左右贴边，本次修改 extension/src/background/capture.mjs，并重新生成 extension/background.js。

- 按正文实际坐标拼接，不再按固定滚动量直接累加每屏高度。
- 每次滚动留 32px 重叠，裁掉已捕获部分；滚动到末屏被浏览器限位时，仍按实际位置取剩余内容。
- 每 60ms 检查一次位置，连续稳定后截图；截图前后坐标变化的帧会丢弃并重拍。
- 临时隐藏输入区、已知滚动按钮及回答外的 fixed/sticky 悬浮层；结束后恢复样式和原滚动位置。
- 成图四周加入正文宽度 5% 的背景色留白，最少 24、最多 48 CSS 像素，原文字尺寸保持。
- 浏览器窗口和视口尺寸不变，不重排或重画正文。
- 不完整截图返回 capture-incomplete，不再把截断图片当作完整结果发送。答案文字仍沿现有流程处理。
- 长图不再固定截到 7000px；上限为 24000 CSS 像素及 3200 万像素画布预算，任一限制触发导致未捕获完整时返回错误。

全部 47 项自动化测试通过，包括末屏限位、2 倍像素密度、截图中页面移动、重叠去除、悬浮层恢复与错误清理。尚未在真实 ChatGPT 页面做端到端验收。真实页面的虚拟列表卸载或持续重排仍可能导致截图无法完整捕获；现有回传请求体大小限制也保持不变。

生效：在 chrome://extensions 重载 GPT Relay Bridge，然后刷新 ChatGPT 标签页。此次只改扩展截图逻辑，worker 无需因本次修改而重启。建议在当前任务结束后重载。
